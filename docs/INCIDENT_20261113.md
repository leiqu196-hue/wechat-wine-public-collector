# November 13 public-link timeout investigation

## Evidence

The existing 07:10, 07:30 and 07:50 China-time 易茅 runs failed:
- https://github.com/leiqu196-hue/wechat-wine-public-collector/actions/runs/43326520669
- https://github.com/leiqu196-hue/wechat-wine-public-collector/actions/runs/43329384912
- https://github.com/leiqu196-hue/wechat-wine-public-collector/actions/runs/43332158589

Dependency installation passed. The bounded search found a November 13 title,
then reported `TimeoutError` with the generic reason `public original unavailable`.
The 17–18 second collection duration is consistent with the 12 second content wait,
but the old diagnostic cannot distinguish this from navigation failure.

Ordinary browser interaction with the matching search result showed that its normal
click handler updates the outbound link and opens the article in a new tab. The
collector instead copied the pre-click href and navigated directly, skipping this
normal site behavior. No redirect parameters or signatures were constructed during
the investigation or in the fix.

## Changes

The collector clicks the verified, current listing anchor normally and inspects the
resulting page. Original publisher, fixed biz, native publication date, and table
checks remain unchanged. Redirect URLs and query parameters are not logged.

Failures distinguish link navigation, direct navigation, and content waiting, with
only an allowlisted host classification. No URL path is retained. Verification checks include the
existing explicit challenge phrases and are repeated after navigation/content
failure and before reading content. A challenge stops collection, rather than
trying another candidate or browser. No login, CAPTCHA solution, proxy, new timer,
cache, permission, or credential changes are added.

## Limits

The navigation defect and diagnostic gaps are demonstrated; they do not establish
that every upstream access failure is fixed. The inspection browser could not
observe the resulting WeChat article because its site-safety gate denied access.
That denial was not bypassed. Live recovery requires a successful authorized
collector run and a current publisher-verified report. Offline tests alone do not
prove recovery or full quotation completeness. Historical files retain their real
dates and must not be presented as current prices.

diagnostic-only follow-up preserves the same `verification_required` stop while
