## Reproduced program defects and changes

- Album discovery's fixed three-row window can miss today's title after pinned or unrelated entries. Inspect up to 20 already-loaded entries, record bounded titles/counts, and use exact month/day (and explicit year when present) matching. No pagination or additional discovery requests were added. Native article validation remains required.
- Search empty results, changed markup, stale titles and verification challenges now produce separate bounded observations. Navigation/launch/timeout errors leave failure reports. Explicit verification stops further queries/engine fallback. No authentication or challenge handling was added.
- `publish.py` previously trusted a successful status and biz, even for an old successful result. It now independently checks source/author/biz, article date, checked_at timezone/date, native timestamp/date and future-time limits **before reading a token or making any network request**. It never relabels retained feeds as today.
- Move search exit status outside the asynchronous task to avoid the existing `SystemExit` cancellation traceback; failed collection still exits nonzero.
- Added offline CI on PR/fix-branch pushes, with read-only permissions and no browser, publisher access or data publishing. No schedule or production configuration changes.
